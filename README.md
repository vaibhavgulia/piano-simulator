# piano-simulator
music instrument simulator - piano keys
interactive web-based piano simulator built using HTML, CSS, and JavaScript.

https://vaibhavgulia.github.io/piano-simulator


Play notes using keyboard keys (A, S, D, F, G, H, J)
Black keys using (W, E, T, Y, U)
Mouse click support on keys
Note labels (C, D, E, F, G, A, B) displayed on keys
Aurora animated background
Fully responsive and hosted on GitHub Pages
